## 글 쓰는 법
상급자에게 보고하듯 명확하게, 전문가답게 쓴다.
- 통상적으로 쓰이는 표현을 쓴다. 업계에서 널리 쓰는 말(MVP, 리텐션 등)은 써도 된다.
- 처음 보는 사람도 이해할 수 있는 단어와 표현으로 쓴다. 작업 중에 스스로 붙인 이름(변수명, 문서의 항목 번호, 약어)은 쓰지 않고, 그것이 무엇인지를 말한다.
- 여러 판단을 명사구 하나에 뭉치지 않고 문장으로 쓴다. (✗ "가치 1·2의 몸통" → ✓ "가치 1·2를 실현하는 기능들")
- 한국어 문장에 영어 낱말을 섞지 않는다. 한국어로 쓸 수 있는 말은 한국어로 쓴다. 코드, 명령, 파일 경로, 라이브러리와 제품 이름은 원래 표기대로 둔다.
